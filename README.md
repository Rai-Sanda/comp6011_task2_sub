# Mental Health Text Classification Project

This repository contains scripts and models for benchmarking various Small Language Models (SLMs) on mental health text classification tasks.

```text
├───results/                # Model outputs and analysis
│   ├───benchmarks/         # Aggregated benchmark summary CSVs
│   ├───figures/            # Visualization plots (PNG)

    └───... (utility and execution scripts)
```
